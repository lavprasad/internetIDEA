# Unit Converter

Offline unit converter for length, mass, volume, and temperature. Open it locally. No install and no network.

## Use

Open `index.html` in a browser.

## Test

```
node test.js
```

## Factor sources

exact SI / international yard and avoirdupois

- Metre, kilogram, and litre are exact SI base units.
- Inch, foot, and mile use the international yard (1 in = 0.0254 m).
- Pound and ounce use the international avoirdupois pound (1 lb = 0.45359237 kg).
- Gallon and cup use the exact US gallon (1 gal = 3.785411784 L).
