# How to use

Open `aptitude/index.html` in a browser.

- **Lesson** on a chapter: notes, tricks, a memory line, and a picture with sliders.
- **Practice** on a chapter: six questions from that chapter.
- **Practice weak spots**: more questions from the skills you have missed most.
- **Misses**: questions whose latest answer was wrong. A later correct answer removes one.

Progress stays in this browser under `aptitude-v1`. Nothing is uploaded.

`node test.js` inside `aptitude/` checks the ranking and that every answer belongs to its choices.
