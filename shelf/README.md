# Shelf

Shelf is a ledger for things that expire. You record a name, a category (food, medicine, document, household, or other), and an expiry date. If something is opened, add the opened date and how many days it lasts after opening. The date that counts is the earlier of the printed expiry and the opened-date window. Active items are listed by that date, with days left and a status: expired, soon (7 days or fewer), or fresh. Mark an item used or wasted to keep it in history, or delete it.

Open `index.html` in a browser. From this folder, run `node test.js`.

Local only, no account.
