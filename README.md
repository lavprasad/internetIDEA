# internetIDEA

Ten single-purpose tools that run in the browser. Nothing is uploaded. Each app stores its own data in `localStorage` on this device.

Open `index.html`, or open an app folder and run `node test.js` for the calculation checks.

| App | What it is |
| --- | --- |
| shelf | Expiry dates, including “use within N days of opening” |
| streak | Habit check-ins and consecutive-day streaks |
| block | Focus timer (25 / 5 / 15, or a custom length) |
| tab | Bill split that conserves cents |
| ledger | Expenses for a month, plus CSV |
| slip | Invoice draft and print view |
| wheel | Decision wheel; the slice is chosen before it spins |
| breath | Box breathing; a 0-second phase is skipped |
| bench | Unit conversion with SI and international factors |
| until | Countdown list |

These follow the local-only pattern of tools such as [perish](https://perish.site), Loop Habit Tracker, and DayTrak: one job, no account.
